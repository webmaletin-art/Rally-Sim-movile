Paquetes de piezas modulares. Cada `*.json` de esta carpeta suma piezas al catálogo (mismo formato que `data/parts.json`: `{"parts": {"id": {...}}}`).
Modelos: GLB, OBJ o malla importada en `res://game/models/parts/` (`source: {"type": "glb"|"obj", "path": "..."}`); `"tint": "body"` hace que la pieza tome el color de la carrocería.
